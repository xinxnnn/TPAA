# 连续性原语复现

`crypto/memauth/continuity_primitives.py` 实现 PDF p8 的 open/upd 两项数学关系，不实现或修正 link、签名运输与 topology 公钥可用性。

PA 使用固定已接受快照 P_old 构造 phi=∏(X-x_i)，精确整除得到 Q=(P_cur-P_old)/phi；非整除直接拒绝。pi_upd=g^(gamma Q(alpha))。点打开使用 O=(P_cur-y)/(X-z)，pi_open=g^(gamma O(alpha))。所有原状态、实际次数、挑战坐标与域都检查，gamma=0 拒绝，不擅自重新散列。

验证端从调用方取得已盲化的旧承诺、K1、同步见证 W、挑战点与独立得到的 y，分别执行更新和点打开配对等式。返回两项布尔值，没有“认证通过”字段，不更新旧快照。完整 topology、身份、link 和签名均未验证。接口不可直接当作授权服务使用。

测试覆盖真实配对、篡改 y、篡改更新证明、无更新时单位元证明、挑战不在原同步快照以及主锚不变。注册记忆实验增加这两项实际计算，工作台显示独立步骤，并保留完整认证未定义状态。

尚未解决的完整认证边界仍按用户此前决定保持诊断，不新增默认公钥运输或修正新旧承诺符号。
