# Phase 4 联合追责等式实验

`accountability_experiment.py` 按 PDF p8 执行：TP 用全局 KTP 派生 SA gamma，逆幂解盲；按 A_mem 查找 RegPA；AP 仅接受自身秘密、DIDAP、AF 和模数以计算 sAP；TP 从 Dec(RF) 去掉掩码后匹配其调用方提供的身份哈希登记集合。

接口不保存身份明文，不让 AP 取得 TP 解密钥或 RF，不让 AP 接口取得整个 TP 注册记录。返回身份哈希只供受限调用方内部使用，默认工作台只记录查找/匹配布尔结果。解盲失败、找不到记录和身份不匹配不会生成成功 Link。重复锚索引拒绝，不补造原文未定义的平局规则。

这是实验 profile 的数学复现，不包含真实举报审批、证据验证、监管签名、安全通道或部署角色隔离。不能从本机同进程角色实验推断真实独立性或匿名认证成功；也不自动允许 TP 单方身份匹配。既有全局 KTP 和登记信息关联风险仍见 algebra-review.md。

registration_memory 入口将此阶段作为独立等式实验显示。Bootstrap 未决项仍维持诊断；该实验不依赖伪造的“认证通过”事件，也不是一次实际获批追责案件。
