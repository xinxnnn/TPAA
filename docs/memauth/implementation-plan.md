# MemAuth 学术复现工程与计算可视化方案

日期：2026-11-10。状态：原语、显式实验签发/记忆链路与静态研究工作台已实现；完整认证、独立可信模块和 AG2 接入未完成。

## 1 实施依据与优先级

主协议来源为 memauth921.pdf 第 V 节 Phase 0–4；522 组会 PPT 独立复现。TPAA 专利及现有 tpaa_v1 保留为身份与能力注册依据，不替代 PDF 凭证。

基线严格复现明确公式。原文未定义的状态转移不自行补充。用户明确确认的执行约定记录为“复现实验约定”，不冒充原文规定。增强默认关闭，不改变基线报文、数学关系或验证条件。发现反例时基线保留，相关增强等待确认。

## 2 已确认决策

| 项目 | 基线与实验约定 | 增强或独立实验 |
|---|---|---|
| KTP | PRF_c1(DID_TP || c2)，c1/c2 为 TP 全局参数 | 每 PA 独立派生，默认关闭，单独审查 |
| SA 主锚 | InitSync 初始锚保持不变，不在 ContVerify 后自动推进 | 版本化原子推进，默认关闭 |
| PA 密钥 | PA 可信模块生成 skPA/PKPA，私钥不交 TP/AP | TP 生成密钥作为独立实验配置 |
| 初始化 | TP 采样 rho0，取得 PA 公钥后计算初始承诺、DIDPA、y0 并签发 | 具体交付封装属于工程运输层 |
| PHC | PDF 凭证保持 y0、sigmaTP、KTP、DIDPA 的定义 | rho0 与密钥库独立，不伪装成原文 PHC 字段 |
| 参数上限 | 配置 Nmax=dmax；同时检查实际多项式次数及 G1/G2 见证次数 | 不实现在线扩展或自动压缩 |
| 密钥恢复 | 独立实验解锁口令，经 KDF 派生加密密钥；口令不落盘且不等于 sUser | 这是软件运行支撑，不是原文认证步骤 |
| 用户秘密 | sUser 仅按需输入；theta_upd 不落盘 | Python 内存清除不宣称硬件安全擦除 |
| 可信模块 | 独立本机服务模拟；无 TEE 防提取保证 | 预留硬件密钥接口 |
| 可视化 | 公开计算默认可看，秘密量进入仅本机合成数据实验视图 | 默认导出不含秘密 |

允许挑战已实际同步保存的历史锚，不自行创造未同步锚。最小基线只保存一次 InitSync；如需额外同步，必须记录真实操作和来源。

初始化依赖顺序：PA 生成密钥并交付公钥；TP 取得 AF/RF 后生成 DIDPA，采样 rho0 并计算 hRoot0，再计算依赖 DIDPA 的 y0；交付 PDF 凭证及必要初始开口；PA 执行 MemBuild。TP 不生成记忆多项式或初始 KZG 承诺。

## 3 协议与代码隔离

协议：tpaa_v1、memauth_pdf_baseline_v1、memory_ppt_experiment_v1、memauth_enhanced_v1。

crypto/memauth 包含 encoding、field、polynomial、pairing_backend、srs、kzg、ps、chameleon、credentials、memory、bootstrap、continuity、accountability。

crypto/memory_experiments/ppt_fixed_commitment 单独保存固定承诺与 alpha 分享实验。crypto/sdk/memauth 为业务入口，crypto/hsm/memauth 为秘密操作接口。

packages/tpaa_memory 管理事件与持久化；packages/memauth_protocol 管理 DTO 和协议状态；packages/tpaa_runtime/memory_adapter.py 定义未来 AG2 接口。仿真器不依赖 AG2。

增强入口独立路由和消息类型；flag_enhance_ktp 等字段只存在于增强消息。基线收到增强字段应拒绝而非隐式切换。是否允许的增强组合逐项审查，不能任意混搭。

## 4 数学层实现

有限域与配对群一致；标量、群元素、字节串使用明确类型。SRS 按 PDF 提供 G1/G2 幂序列，验证 srsId 和次数界限。优先评估 BLS12-381 成熟库，后端具体选择记录到锁文件。

多项式支持规范系数、求值、插值、消失多项式、精确除法。重复坐标、零分母、非零余数、超次数显式报错。Nmax 不代替实际 degree(P) 检查。

实现 PS、KZG、变色龙哈希及 PDF 的身份绑定、点打开、更新关系证明。原语逐项有独立计算向量。不得用整数模拟群并标为真实密码学实现。

实验 SRS 生成与运行服务分开；PDF 运行路径不提供 alpha 恢复接口。PPT 恢复 alpha 的路径仅存在于实验协议。

## 5 身份、存储与信任边界

TPAAPHC 与 MemAuthCredential 分离，通过内部注册证据关联。不可把 AF/CMI 直接改名成 y0。

TP RegPA 保存 A_mem、DIDPA、RF、AF。PII/BI 密文及 ECID 沿用 TPAA 存储机制，不能声称其由 PDF 定义。AP 的逐 PA 注册信息仅保存 AF；AP 自身密钥与公共配置另行保存。

PA 可信侧保存加密凭证、密钥材料、计算所需记忆状态和见证；外部事件存储允许攻击注入。原始敏感事件加密保存，证明按 PDF 使用摘要序列。私钥不经过 AP 或模型运行时。

TP 持有 Paillier 私钥时可以解密 RF 得到带掩码的值；缺少 sAP 时不能按正规 R1 直接移除掩码。这不自动证明整个工程无法由 TP 单方关联：TPAA 历史记录、注册映射以及 TP 已见信息必须单独审查。不得将“AP 有 AF 才能执行协查”当作 AF 是秘密的安全假设。

## 6 记忆和认证

MemoryEvent 对应时间、动作、对象、主体、方法。宏节点保存坐标、事件摘要序列、Merkle 根、变色龙承诺及 y。MemoryState 保存宏节点、多项式、承诺、SRS 标识与身份锚。

MemBuild：MN0=(0,y0)，结合初始交互宏节点插值，PA 计算 CP0。

APPEND：更新 Seq 和 Merkle 根，适配 CH，检查宏节点外部承诺保持。

CREATE：依 PDF 构造授权点与历史消失因子、增量插值和新多项式；检查新旧点约束、授权点约束及实际次数。超限在提交前拒绝，保留旧状态。

基线 topo 按 PDF 输出开口和完整被挑战宏节点摘要序列，不替换成 Merkle 路径。

InitProve、InitVerify、InitSync、ContChallenge、ContProve、ContVerify、Deanonymize 为无 I/O 的纯协议函数。基线认证后保留主锚。工程存储索引和运行编号不进入原文密码报文。

## 7 AG2 接入契约

EventSource 提供规范事件；GraphAdapter 提供关系；MemoryRepository 提供状态读取/提交；MemoryAuthorizer 提供按需授权；SecretProvider 提供受限签名和派生；MemoryAuthenticator 提供初始/连续认证。

当前实现 SyntheticEventSource、DeterministicGraphAdapter、LocalMemoryRepository、TestSecretProvider、SimulatedPA、SimulatedSA。未来 AG2 替换输入输出适配器，密码层无需 import AG2。

## 8 可视化布局

新建独立研究工作台 apps/research-web。与既有用户申领页面分开，复用样式，不复用业务权限。主导航：实验配置、参数初始化、身份签发、记忆构建、记忆更新、初始认证、连续认证、联合追责、反例与性能。

固定顶部显示协议、来源页码/算法、运行编号、角色、参数集、SRS ID、是否合成数据。基线与增强使用明显标签。主界面三列：左侧算法步骤，中间公式与代入值，右侧验证条件与输出。底部显示真实消息和计算时间。

窄屏变为上下布局，公式和长整数允许展开/复制，不以省略后的字符串参与比对。每个步骤支持“执行此步”“执行到此步”“重新建立独立实验”，不自动重放签发、更新等变更操作。

### 8.1 计算面板统一格式

每个计算显示：原文定位、数学公式、输入类型与来源、实际输入、规范编码字节、运算、实际输出、独立验证式、后端实现位置、耗时、状态。

结果区分：通过、失败、未执行、超限拒绝、原文未定义、已知反例。不得把“公式成立”显示为“整体安全”。静态说明和真实计算记录使用不同样式。

计算记录为可信执行路径产生的旁路观察对象，不加入基线协议消息，不作为验证的可信输入。前端不重新制造密码结果。验证方从实际消息计算左右两侧，再记录验证结果。

### 8.3 双层透明度

普通视图显示公开量、公式和秘密符号；秘密值不发送浏览器。仅本机合成数据秘密实验视图，经显式操作读取本次内存计算快照，支持查看私钥、授权点和系数。必须标明这会突破论文敌手不可见秘密的假设，不能用这些转录声称隐私。

sUser、theta_upd、解锁口令不写入持久 trace、日志、浏览器存储或默认导出。秘密实验视图仅在已有内存值时可看，不为查看而落盘。PPT 的 alpha 与 PDF 已销毁 alpha 明确区分；PDF 不显示虚构 alpha。

### 8.4 图示与导出

支持事件到宏节点的图关系、Merkle 树、旧新多项式约束表、PA/SA 消息时序、三项证明验证表。实数绘图仅为有限域系数的教学投影，不代替有限域验证。

默认导出公开 trace.json、协议消息、结果表与参数摘要。重现实验需明确 fixture 和后端版本；含秘密的确定性测试向量独立保存在测试资源中，不当作真实随机运行种子发布。随机密文不同不等于复现失败，以数学关系和验证结果对标。

## 15 独立实验审计封装（2026-11-10）

用户批准：独立实验审计封装，从 TP/AP 允许公开的实际操作产物生成五元事件与 Seq1/Seq2。代码只接受类型化白名单：AP 的 RF 密文，TP 的 PKPA/deltaTP；不接受整个内部对象、PII、BI、KTP、rho0、私钥或 sUser，也不对它们产生可猜测摘要。输出来源操作、字段清单和公开编码；不新增基线报文字段。

审计观察不等于认证的证据；注册公钥、签名和密文可能关联身份注册，故转录仅供注册实验查看，不当作匿名认证转录。完整签发尚未接入时，演示必须标注合成输入，不能声称真实完成 PHCInit/PAConstruct/PHCFinalize。
