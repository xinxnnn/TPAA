# 独立实验审计封装

已按用户批准实现于 `crypto/memauth/audit_events.py`。它是实验旁路观察对象，不是 PDF 新消息、额外签名或安全证明。

| 来源 | 允许的实际输出投影 | 排除 |
|---|---|---|
| AP PAConstruct | RF 密文 | 身份明文、PII/BI 摘要、CMC 明文/猜测摘要、sAP、私钥 |
| TP PHCFinalize | PKPA、deltaTP | y0、KTP、rho0、私钥、sUser、身份明文及其摘要 |

只能构造类型化公开投影，传入任意字典或内部凭证对象会被拒绝。将秘密伪装成公开字段不可能仅靠类型判断检测，调用方仍必须从实际操作输出映射；此层不证明密文合法性或来源真实性。

事件为 `(操作时间, 算法动作, sha256:公开投影摘要, 角色DID, 实验方法)`。摘要输入采用已确认 MA1 编码，含封装版本、操作名、字段名和字段值；事件经实验 H2 得到摘要。记录列明来源字段、公开投影编码和 H2，方便逐项复算。调用者显式提供时间，库不伪造操作时间，也不将系统时间当作签名时间戳。

PA 侧适配器将 TP 事件作为 Seq1、AP 事件作为 Seq2，分别构造宏节点后 MemBuild。检查事件封装完整性、操作来源类型和 PA 公钥匹配；不执行 PHC 签发、不验证身份，也不把观察记录当作已认证审计证据。

注册阶段公开工件可能关联注册，输出不得作为匿名认证记录发布。默认输出不含 CH 开口、系数或秘密。调用方传入的角色 DID/时间也不得塞入 PII 或秘密。

演示：

```powershell
python -m demos.memauth.audit_memory --srs memory-experiment-srs.json
```

演示签名来自真实签名运算；RF 与 y0 为明确标注的合成夹具，不声称已完成完整签发。输出包括字段白名单、摘要编码、Seq1/Seq2 检查和真实初始记忆承诺。完整签发完成后调用同一适配器替换夹具。
