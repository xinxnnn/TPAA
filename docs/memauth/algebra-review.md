# MemAuth P0 代数审查

状态：初步审查，2026-11-10。此文不修改原协议。数值诊断运行 `python demos/memauth/audit_algebra.py`，其指数模型仅检查等式，不能当作真实 KZG 或配对实现。

## A01 身份绑定证明等式

PDF p7 InitProve 给 L(X)=(Pcur(X)-Pz(0))/X，pi_link=g^(gamma L(alpha))；p8 InitVerify 原页实际打印 e(CPcur/A_mem,h)=e(pi_link,h^alpha)。已渲染并视觉核验第 7、8 页：此前文本提取遗漏右侧上标，不是原文公式错误。

若 Pcur(0)=Pz(0)=y0，则 CPcur/A_mem=g^(gamma alpha L(alpha))，与原页验证式一致，无需修改此等式。p8 ContVerify 的 link 校验使用旧 CPz，而证明定义使用当前 Pcur，仍存在另一项新旧状态不一致。

例：q=101，alpha=7，gamma=11，P(X)=13+5X。原页等式左右指数均为82；错误省略 alpha 才会得到右侧55。

Bootstrap 中 Pz、gamma_C 在首次使用时未定义：同段使用的是 gamma_B。此命名问题已在原页确认，具体解释仍待确认，不自动替换。

## A02 全局 KTP 与多 PA 观察

已确认基线 c1/c2 为 TP 全局参数，因此 KTP 对同 TP 下的 PA 相同。同一 SA 的 gamma 和 K1 也相同，K1 本身区分的是 SA，而非 PA。

获得一份自身凭证 KTP 的恶意注册 PA，可以计算同 TP 下各 SA 的 gamma，并对看到的 A_blind 做逆幂恢复 A_mem。因此若威胁实验允许这种注册及观察，必须进一步核对不可关联定义是否排除该能力。不能直接据此声称已推翻论文全部安全游戏，也不能忽略该条件性反例。

增强每 PA 独立 KTP 会改变 TP 解盲查找方式：TP 尚不知道 PA 时，不能直接从 DIDPA 派生其 KTP。需要新的检索/打开设计，不是加一个字段即可完成。增强仍默认关闭。

## A03 公开多项式的授权点泄漏

CREATE 增量包含 (X-theta_upd) 与历史消失因子。若攻击者能读取相邻状态的完整多项式系数，则可对差分多项式求公共零点或公因子，排除已知历史坐标后可能识别 theta_upd。提供小域合成例说明条件，不作大域穷举性能结论。

这不必然意味着攻击者得到受保护的 PA 私钥，但会影响“缺少 sUser 无法形成授权点约束”的论证。应明确多项式究竟位于可信模块内部还是不可信外部存储。秘密实验视图若导出系数，会改变敌手知识，不能沿用不泄露系数的结论。

## A04 CH 公开双开口

对 CH(m;rho)=g^H(m) PK^rho，若同一个 PK 下两组不同消息的开口公开，sk=(H(m)-H(m'))/(rho'-rho) mod q。PDF topo 发送 rho 与事件序列，因此多轮 APPEND 中 SA 可能观察到同一 hRoot 的多个开口。若 PKPA 同时承担签名或派生根，需分析影响。原文复现保留，但要单独实验，不复用既有 TPAA“隐藏开口”的安全结论。

## A05 可执行性缺项

ContVerify 需要 PKPA 验证 CH，但常规盲化消息中如何取得它尚不明确；直接增加全局 PKPA 可能破坏不可关联目标。ContProve 输出 CPnew，ContVerify 解析处写 CPz；link 的新旧承诺也不一致。不得通过默认额外传输全局字段补齐。

Hash-to-field 的零输出会令 gamma 不可逆，随机数与私钥的非零要求需要结合原文定义固定。Merkle 奇数叶、空序列、Adjudicate 平局和具体编码同样需单列工程约定。

## A06 PPT 已知陷门

知道 alpha 时，对任意 z!=alpha、任意 y，可以取 pi=(C/g^y)^(1/(alpha-z))，通过点打开配对关系。PPT 实验必须展示该反例；PDF 运行路径不允许恢复 alpha。

## A07 变色龙哈希双开口复核

PDF p4 原页视觉确认 `CH.Gen_PK(m;rho)=g^{H0(m)}PK^rho`，适配式为 `rho'=rho+(H0(m)-H0(m'))sk^{-1} (mod p)`。代码按原式实现；H0 字节编码单独标为本地约定。若同一公钥下公开同一承诺的两组不同消息开口，私钥可由差分求得；适配测试不能当作抗碰撞安全证明。密钥跨功能复用策略尚未确认。

### A08 PHC 固定基底签名的双凭证线性组合诊断

原页 p6 明确 delta(y)=g^(c1+c2*y)，不同凭证使用同一基底 g 和 TP 参数。若观察者获得同一 TP 签发的两个不同、已知标量 y_a/y_b 及对应 delta_a/delta_b，则无需离散对数即可构造任意目标 y 的签名：t=(y-y_a)/(y_b-y_a)，delta=delta_a^(1-t) delta_b^t。该 delta 通过固定基底配对等式。真实配对测试以 7、8 推出 9 复核。

这针对 Phase 0 打印的固定基底形式，不是对 III.B 使用每签名随机基底 PS 的同一结论。是否能获得两份同 TP 凭证，以及伪造 y 是否能进一步构成被接受的完整身份/追责记录，必须按威胁游戏及注册检查单独分析，不能仅据此宣布完整协议攻击成功。原式保留，只记录诊断；不擅自改为标准 PS 或添加证明字段。
